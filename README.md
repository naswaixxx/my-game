# Словоловка

**Автор:** Салимов Максим Александрович
**Группа:** Б9125-02.03.01сцт

Игра на Node.js и Vite без фреймворков. Шарик отскакивает от стен, и при каждом ударе в списке появляется новое слово. Набирайте слова из списка и нажимайте Enter: слово пропадает, а вы получаете очки (длина слова × уровень). Если слов в списке становится больше 8 или вы делаете 5 ошибок, игра заканчивается. Каждые 5 слов уровень растёт, а шарик ускоряется. Каждая ошибка тоже ускоряет шарик. Рекорд и состояние игры сохраняются в браузере, а после перезагрузки страницы шарик продолжает движение с того же места.

## Запуск

Нужна актуальная LTS-версия [Node.js](https://nodejs.org) (см. `.nvmrc`, минимум 22).

```bash
npm ci           # установка зависимостей по package-lock.json
npm run dev      # режим разработки: http://127.0.0.1:5173
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной игры
```

## Проверки

```bash
npm test             # правила игры (Node, без браузера)
npm run lint         # ESLint
npm run format       # привести код к единому виду (Prettier)
npm run format:check # только проверить форматирование
```

## Устройство

- `src/gameLogic.js` — правила игры в виде чистых функций, без браузера.
- `src/words.js` — словарь слов.
- `src/main.js` — ввод, отрисовка и игровой цикл. Обработчики событий только меняют состояние, а DOM обновляется в игровом цикле.
- `canvas-confetti` — эффект при повышении уровня.


# Clicker Game
**Автор:** Салимов Максим Александрович
**Группа:** Б9125-02.03.01сцт

Игра на Node.js и Vite без фреймворков. Вы добавляете цели в список (+10 очков и конфетти), удаляете их, а по полю ездит шарик. Прогресс сохраняется в браузере.

## Запуск

```bash
npm ci           # установка зависимостей по package-lock.json
npm run dev      # режим разработки: http://127.0.0.1:5173
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной игры
```

## Проверки

```bash
npm test             # правила игры (Node, без браузера)
npm run lint         # ESLint
npm run format       # привести код к единому виду (Prettier)
npm run format:check # только проверить форматирование
```

## Устройство

- `src/gameLogic.js` — чистые функции правил игры (тестируются в Node).
- `src/main.js` — ввод, отрисовка и игровой цикл. Обработчики событий только меняют состояние, а DOM обновляется в игровом цикле.
- Зависимость `canvas-confetti` отвечает за эффект конфетти.
- Скорость шарика задана в пикселях в секунду и считается по времени кадра, поэтому одинакова на 60 и 120+ Гц. Время кадра ограничено, поэтому после возврата на вкладку рывка нет.
- Испорченное сохранение игнорируется, начинается новая игра.

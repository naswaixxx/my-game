# Словоловка

**Автор:** Салимов Максим Александрович
**Группа:** Б9125-02.03.01сцт

Игра на React и TypeScript. Шарик отскакивает от стен, и при каждом ударе в списке появляется новое слово. Набирайте слова из списка и нажимайте Enter: слово пропадает, а вы получаете очки (длина слова × уровень). Если слов в списке становится больше 8 или вы делаете 5 ошибок, игра заканчивается. Каждые 5 слов уровень растёт, а шарик ускоряется. Каждая ошибка тоже ускоряет шарик.

Часть слов приходит от внешнего партнёра: это названия статей русской Википедии, которые начинаются на выбранную игроком букву. Игра, рекорд, набранный текст, точное положение шарика и настройки (тёмная тема, выбранная буква) сохраняются в браузере.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 22.18 или новее (см. `.nvmrc`).

```bash
npm ci            # установка зависимостей по package-lock.json
npm run dev       # разработка с настоящим API Википедии: http://127.0.0.1:5173
npm run dev:stub  # разработка с заглушкой вместо API, интернет не нужен
npm run build     # проверка типов и продакшн-сборка в папку dist
npm run preview   # просмотр продакшн-сборки (с настоящим API)
```

### Адрес API

Адрес партнёра задаётся переменной окружения `VITE_API_URL`:

- `.env` — адрес по умолчанию, `https://ru.wikipedia.org` (используют `npm run dev`, `npm run build`, `npm run preview`);
- `.env.stub` — адрес заглушки, `/partner-stub` (использует `npm run dev:stub`);
- чтобы указать другой адрес только у себя, создайте файл `.env.local` со строкой `VITE_API_URL=...`: он не попадает в git.

Адрес вшивается в код при сборке, поэтому после смены переменной сборку нужно повторить.

### Заглушка: медленный ответ и ошибка сервера

Заглушка встроена в dev-сервер Vite (`stub/partnerStub.ts`) и отвечает так же, как Википедия. Режимом ответа можно управлять без изменения кода, пока запущен `npm run dev:stub`. Откройте адрес в браузере (порт смотрите в консоли, по умолчанию 5173):

| Адрес                                                                | Что делает                            |
| -------------------------------------------------------------------- | ------------------------------------- |
| `http://127.0.0.1:5173/partner-stub/__control?delay=3000`            | каждый ответ приходит через 3 секунды |
| `http://127.0.0.1:5173/partner-stub/__control?status=500`            | сервер отвечает ошибкой 500           |
| `http://127.0.0.1:5173/partner-stub/__control?delay=3000&status=503` | и то и другое сразу                   |
| `http://127.0.0.1:5173/partner-stub/__control?reset`                 | вернуть обычный режим                 |

В заглушке есть слова на большинство букв; на «Ы», «Ь», «Ъ» ничего нет, это удобно для проверки сообщения «Ничего не найдено».

## Проверки

```bash
npm test             # Vitest: правила игры, загрузка, компоненты (без сети)
npm run test:e2e     # Playwright: сценарии в настоящем браузере (сам запускает приложение с заглушкой)
npm run typecheck    # строгая проверка типов TypeScript
npm run lint         # ESLint
npm run format       # привести код к единому виду (Prettier)
npm run format:check # только проверить форматирование
```

Перед первым `npm run test:e2e` браузер Chromium скачивается автоматически (скрипт `pretest:e2e`), нужен интернет.

## Устройство

- `src/gameLogic.ts` — правила игры, чистые функции и редьюсер `gameReducer`; `src/random.ts` — генератор случайных чисел с состоянием (seed лежит в состоянии игры, поэтому редьюсер остаётся чистым и каждое событие получает своё случайное число).
- `src/storage.ts` — сохранение игры в `localStorage` и безопасное чтение сохранения.
- `src/store/` — маленькое хранилище игры (`createStore`) и контекст `GameProvider`: компонент подписывается только на нужное поле, поэтому кадры анимации не перерисовывают весь интерфейс.
- `src/settings/` — настройки игрока (тема, источник слов): `useReducer` + Context, сохраняются в `localStorage`.
- `src/partner/` — работа с API партнёра: `api.ts` (запрос и проверка ответа), `useWordPack.ts` (состояния «загрузка / ошибка / готово», отмена устаревших запросов, повтор), `WordsContext.tsx`.
- `src/game/` — `useGameEngine` (цикл анимации и сохранение, в том числе при закрытии страницы) и `useGameActions`.
- `src/components/` — `Stats`, `GameField`, `WordList`, `Controls`, `StatusMessage`, `Rules`, `SourcePanel`, `ThemeToggle`. Компоненты берут нужные данные из контекстов, через props между ними ничего не передаётся.
- `stub/` — заглушка API для разработки и e2e-тестов.
- `e2e/` — сценарии Playwright, `src/**/*.test.ts(x)` — тесты Vitest и React Testing Library.

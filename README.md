# Словоловка

**Автор:** Салимов Максим Александрович
**Группа:** Б9125-02.03.01сцт

Игра на React и TypeScript. Шарик отскакивает от стен, и при каждом ударе в списке появляется новое слово. Набирайте слова из списка и нажимайте Enter: слово пропадает, а вы получаете очки (длина слова × уровень). Если слов в списке становится больше 8 или вы делаете 5 ошибок, игра заканчивается. Каждые 5 слов уровень растёт, а шарик ускоряется. Каждая ошибка тоже ускоряет шарик. Игра, рекорд и набранный, но не отправленный текст сохраняются в браузере.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 22.18 или новее (см. `.nvmrc`).

```bash
npm ci           # установка зависимостей по package-lock.json
npm run dev      # режим разработки: http://127.0.0.1:5173
npm run build    # проверка типов и сборка в папку dist
npm run preview  # просмотр собранной игры
```

## Проверки

```bash
npm test             # правила игры (Node, без браузера)
npm run typecheck    # строгая проверка типов TypeScript
npm run lint         # ESLint
npm run format       # привести код к единому виду (Prettier)
npm run format:check # только проверить форматирование
```

## Устройство

- `src/types.ts` — типы состояния игры и действий.
- `src/gameLogic.ts` — правила игры: чистые функции и редьюсер `gameReducer`.
- `src/storage.ts` — сохранение в `localStorage` и безопасное чтение сохранения.
- `src/words.ts` — словарь слов.
- `src/hooks/` — `useGame` (состояние и цикл игры), `useAnimationFrame`, `useOnIncrease`, `useLatest`.
- `src/components/` — `Stats`, `GameField`, `WordList`, `Controls`, `StatusMessage`, `Rules`.
- `src/App.tsx` — собирает компоненты вместе.
- `canvas-confetti` — эффект при повышении уровня.

Всё состояние лежит в одном редьюсере, компоненты получают из него только нужные им данные и не перерисовываются без необходимости, поэтому поле ввода не теряет фокус и текст. Случайность передаётся в редьюсер в действии, поэтому он остаётся чистой функцией.
